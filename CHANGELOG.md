# Changelog

## 1.0.1

- Move Java packages and the Gradle group to `io.github.yuutaro.randomizefiltersterrainslabsfix`.
- No changes to the mod ID, dependencies, or gameplay behavior.

## 1.0.0

- Initial release for Minecraft 1.21.1 / NeoForge.
- Use Terrain Slabs' 50 block-to-slab mappings for mechanical rollers with Random Filters and Advanced Random Filters.
- Preserve the original lookup for blocks outside Terrain Slabs' mapping table.
- No Sequence Filter support or changes to Create's ordinary filters.
